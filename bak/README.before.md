# 我的小屋 · 第一版

一个以手绘房屋为入口的个人网站原型。当前迭代按用户提供的视频完成正面大门、入门欢迎、首扇房门三个关键画面，以及从院子进入收藏展廊的本地体验；构图与空间效果参照视频，不宣称逐像素复刻。

## 本地预览

要求 Node.js 22.12+。

```powershell
npm install
npm run dev
```

打开 [本地预览](http://127.0.0.1:4317/) 。生产版本使用 `npm run build` 构建，`npm run preview` 预览。

## 已完成

- 正面平视的庭院入口、红棕色大门、透明树木素材，以及近白色线描室内。
- 开门后穿过同一空间中的门槛；场景内欢迎文字随靠近淡出。
- 可前后行走的长走廊；依次经过左侧收藏展廊、右侧书房、左侧空白房间。
- 电脑滚轮、手机上滑推进，反向后退；沿途靠近房门后进入，从房间返回原位置。
- 点击三维房门与按钮导航；开门、镜头移动和转场。
- 展廊悬挂三张可点击的作品纸，配有栏杆、云朵和远处城市线稿；收藏目录默认收起，可通过普通按钮展开。
- 文章阅读、画作查看、小屋地图、浏览器本地改名。
- 桌面与手机构图；减少动态模式；可选的本地合成环境声。
- 键盘可访问的导航和原生对话框。

## 替换内容

- 房间名称、文章、画作标题：`src/content.ts`。
- 场景、家具、门位、镜头与展廊自适应：`src/World.tsx`。
- 新门面、欢迎文字、悬挂纸张、植物与城市线稿：`src/ink.ts`。
- 基础手绘纹理、招牌和示例插画：`src/sketch.ts`。
- 页面、导航和滚动交互：`src/App.tsx`。
- 基础样式：`src/style.css`；本次视觉覆盖层：`src/experience.css`，在基础样式之后加载。

三篇文章和三幅插画均为演示内容。网站暂未接入服务器、账户、上传、留言或内容管理系统；名字只保存在当前浏览器。第一版先供本地体验，尚未部署或绑定域名。

## 素材与字体

庭院树木使用一张由内置 imagegen 生成、具有真实透明通道的图片：`public/assets/garden-tree.png`。其余场景几何、线稿纹理、图标、示例插画与环境声由项目代码生成。生成提示词及素材来源见 [ASSETS.md](.qa/visual-update/ASSETS.md)。视频截帧只用于 QA 对照，没有作为网站素材加载。

标题字体为 LXGW WenKai TC（作者 LXGW），从 Google Fonts 获取并以页面所需字符子集自托管。许可见 `public/fonts/OFL.txt`；新增文字若不在子集中会使用系统楷体。见 [原始字体项目](https://github.com/lxgw/LxgwWenKaiTC)。
